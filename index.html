The Situation
Before  ·  2021
  • No data infrastructure. Zero.
  • Finance, Sales & CS each had their own ARR number — all different
  • 80+ employees with no access to data. Everything was Slack requests
  • Compliance tracking done manually in spreadsheets
  • CEO making decisions from weekly manually-assembled slide decks
  • Churn discovered after the renewal conversation failed
After  ·  2025
  • Full medallion data stack: 9 source systems → Snowflake → BI layer
  • One ARR number. One owner. Auditable SQL behind every figure
  • 80+ non-technical users self-serving via natural language AI queries
  • 86.7% automated compliance completion across 850+ registered reps
  • CEO sees live ARR, pipeline, GRR, runway — refreshed weekly
  • CS gets churn alerts before the renewal call. GRR: 93% → 98%
What I Built
01
The Full Data Stack
Ingestion (Hevo + Snowpipe), warehouse (Snowflake), transformation (dbt), BI (Sigma). 9 source systems. 7 business domains. Built from scratch.
02
Governed Semantic Layer
~50 KPIs version-controlled in SQL. Every metric has one definition, one owner, one variance threshold. Ended cross-team metric disputes permanently.
03
CEO & ELT Dashboard
Weekly live view of ARR ($8.5M+), qualified pipeline ($2.3B+), GRR, NRR, bookings, runway. Replaced 4 manual reporting streams on day one.
04
AI Natural Language Layer
Deployed Snowflake Cortex Analyst over the semantic layer. 80+ non-technical users now query data in plain English. Cut manual data requests by 80%+.
05
Churn & Escalation Intelligence
Unified 360° customer signals into a sentiment engine with churn classifiers. CS now intervenes proactively. GRR improved 93.1% → 98.2% QoQ.
06
Compliance Surveillance System
Automated FINRA attestation workflows for 850+ registered reps. Email surveillance via Smarsh with 9-policy keyword detection. 86.7% completion rate.
